# Statistical-test-for-the-mean
You can perform t-tests and analyses of variance (ANOVA) based on your data, with the option to select either paired or unpaired tests.
# データ比較　自動分析　マニュアル
〜教員と学生のための、迷わない統計解析ガイド〜

## 1. はじめに
本アプリは、教育現場や研究において「どの統計検定を使えばいいかわからない」「RやSPSSの設定が難しい」と悩む教員や学生のために開発されました。
ブラウザ（HTML）だけで動作し、データを読み込ませるだけで最適な検定手法を自動判定、グラフ化、さらには論文用のAPAフォーマットまで一瞬で出力します。

## 2. 具体例で学ぶ基本の3ステップ

ここでは、教育現場でよくある **「指導法Aと指導法Bで、テストの点数に差があるか？」** を確かめるケースを例に解説します。

### Step 1: データの読み込み
1. 分析したいデータが入力されたCSVファイルを用意します。
2. アプリ画面の「📂 ここにCSVファイルをドラッグ＆ドロップ」の領域にファイルを投げ込みます。
3. 読み込みが完了すると、「Step 2: 分析条件の設定」が表示されます。

### Step 2: 分析条件の設定
画面に表示された項目から、目的に合わせて設定を行います。

*   **比較する値（複数選択可）：** 点数などの「数値」が入っている項目にチェックを入れます（例：「テスト得点」）。
*   **群分け（対応なし）：** クラスや指導法など、グループを分ける項目を選びます（例：「指導法クラス」）。
*   **ID（対応あり）：** 事前・事後テストのように、同一人物を複数回測定した場合は、個人を特定する項目（例：「生徒ID」）を選びます。

設定後、**「統計分析を実行する」**ボタンを押します。

### Step 3: 結果の解釈と論文への活用
ボタンを押すと「Step 3: 分析結果」が開き、以下の情報が出力されます。

1.  **JS Stat Engine 解析レポート：** アプリが裏側で判断した「群数」「対応の有無」「正規性の有無」と、それに基づき選択された「最適な検定手法」がバッジで表示されます。
2.  **データの可視化（グラフ）：** 正規性があれば「平均値とエラーバー」、なければ「箱ひげ図」が自動で描画されます。
3.  **論文記述テンプレート（APA形式）：** そのままレポートや論文にコピペして使える文章が出力されます。

## 3. 🚨 初心者が必ずつまずく「データ構造の落とし穴」

統計ソフトを使う際、9割の初心者がエラーを出して挫折する原因があります。それが **「横持ち（Wide）データ」** と　**「縦持ち（Long）データ」** の違いです。

### ❌ 横持ちデータ（初心者が作りがち）
Excelでよく見る、1人のデータが横に伸びていく形式です。
| 生徒ID | 事前テスト | 事後テスト |
| :--- | :--- | :--- |
| 001 | 60 | 80 |
| 002 | 55 | 70 |

*   **アプリでの使い方：** 「比較する値」で「事前テスト」と「事後テスト」の**2つ**にチェックを入れます（群分け指定は不要です）。アプリが裏側で自動的に縦持ちに変換して計算します。

### ⭕ 縦持ちデータ（統計ソフトが好む形式）
1行に「1つの測定結果」が入る形式です。
| 生徒ID | 実施時期 | テスト得点 |
| :--- | :--- | :--- |
| 001 | 事前 | 60 |
| 001 | 事後 | 80 |

*   **アプリでの使い方：** 「比較する値」で「テスト得点」のみにチェックを入れ、「群分け」で「実施時期」を指定します。

---

## 4. 💡 統計の「事実」と「推測」を分ける

本アプリでは、画面上に **「期待される大小関係（事実）」**　と、**「APA形式の検定結果（推測）」**　の2つを出力します。ここを混同してはいけません。

*   **事実（平均値の比較）：** アプリ画面に出る `事後テスト(M=75.0) ＞ 事前テスト(M=57.5)` は、単なる計算結果（事実）です。
*   **推測（統計的有意差）：** その差が「偶然の誤差」ではなく「指導法による本質的な効果」であると推測できるかは、**p値（有意確率）**を見なければ分かりません。p値が0.05未満（p < .05）であれば、「統計的に意味のある差（有意差）がある」と論文に記述できます。

## 5. JASPとの連携（さらに厳密な分析へ）

本アプリはブラウザ単体で計算を完結させますが、事後検定の詳細な構造や、論文投稿レベルの厳密な証明には、無料の統計ソフト「JASP」の利用を推奨します。

**【JASPでの実行手順】**
1. JASPを起動します。
2. 画面右上の「＋」アイコンをクリックし、**「R (Beta)」** にチェックを入れて有効化します。
3. 上部メニューに現れた「R」アイコンをクリックします。
4. アプリ画面の一番下に出力されている **「💻 JASP Rコンソール用 再現コード」** をコピーし、JASPの黒いエディタ画面に貼り付けます。
5. **「Run Code」** ボタン（またはCtrl+Enter / Cmd+Enter）を押します。

※データ自体がコード内に埋め込まれており、必要なパッケージも自動でインストールされるため、初心者でもファイル読み込みエラーを起こすことなく、一発で完璧な統計結果を得ることができます。
